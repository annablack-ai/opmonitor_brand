# 官网页面结构梳理（V1）

## 1. 站点目标与用户路径
1. 让首次访问者快速理解公司定位与产品边界。  
2. 让有明确需求的医院/机构用户，3 步内进入对应产品线和方案页。  
3. 让采购/管理层快速看到“解决什么问题、怎么落地、有哪些硬件、有没有案例、怎么联系”。

---

## 2. 顶层信息架构（Sitemap）
1. 首页 Home  
2. 产品中心 Products  
3. 解决方案 Solutions  
4. 智能硬件 Hardware  
5. 客户案例 Cases  
6. 服务与支持 Service  
7. 关于我们 About  
8. 联系我们 Contact

---

## 3. 导航逻辑（一级到二级）
| 一级导航 | 二级页面 |
|---|---|
| 首页 | 品牌主张、产品线入口、核心能力、案例精选、联系 CTA |
| 产品中心 | 内镜、医废、手卫生、智慧卫监（每条产品线一个落地页） |
| 解决方案 | 综合解决方案、按客户类型、按场景类型、按建设阶段 |
| 智能硬件 | 硬件总览、按产品线分类、单品详情页 |
| 客户案例 | 按产品线筛选、按地区筛选、按医院等级筛选 |
| 服务与支持 | 实施交付、运维服务、培训体系、文档下载、常见问题 |
| 关于我们 | 公司介绍、资质荣誉、研发实力、服务网络、新闻动态 |
| 联系我们 | 总部联系方式、区域办事处、表单咨询、预约演示 |

---

## 4. 页面层级模型（重点）
## 4.1 首页（品牌与分发页）
1. Hero：公司定位 + 核心价值 + 主 CTA（预约演示）。  
2. 产品线矩阵：内镜/医废/手卫生/智慧卫监四宫格入口。  
3. 解决方案总览：综合方案 + 客户分层方案。  
4. 智能硬件总览：关键硬件卡片。  
5. 案例与数据：覆盖省份、客户数量、典型医院。  
6. 联系入口：400 电话 + 留资表单。

## 4.2 产品线落地页模板（每条产品线统一）
1. 产品线定位与痛点。  
2. 综合解决方案（端到端业务闭环）。  
3. 分类型方案（按客户类型/规模/场景）。  
4. 智能硬件组合（主设备+配件+部署方式）。  
5. 软件平台能力（可视化、追溯、预警、报表）。  
6. 成功案例。  
7. 交付与服务。  
8. CTA（预约演示/下载资料/联系销售）。

## 4.3 解决方案中心页
1. 方案总图（按产品线 + 按客户类型双维度）。  
2. 综合方案卡片。  
3. 客户类型方案入口。  
4. 场景方案入口。  
5. 建设阶段方案入口（新建/改造/升级）。

## 4.4 智能硬件中心页
1. 硬件能力总览（感知、采集、通信、控制）。  
2. 按产品线分类列表。  
3. 单品详情（参数、安装方式、对接系统、应用场景）。  
4. 与软件平台联动示意。

---

## 5. 内容对象模型（你后续建页可按这个填）
| 内容对象 | 必备字段 |
|---|---|
| 产品线 | 定位、核心痛点、核心能力、典型场景、关联硬件、关联案例 |
| 解决方案 | 目标客户、业务流程、建设范围、实施周期、交付成果 |
| 硬件产品 | 产品名、功能、参数、安装方式、适配场景、配套软件 |
| 案例 | 客户类型、建设前问题、实施内容、效果指标、上线周期 |

11. `/about` 关于我们  
12. `/contact` 联系我们

---

## 7. 把“画册内容”转官网的映射方式（以内镜为例）
1. 画册首页内容 -> 产品线页 Hero + 核心卖点。  
2. 行业洞察/合规要求 -> 产品线页“价值与合规模块”。  
3. 阶梯化版本矩阵 -> 产品线页“版本与配置模块”。  
4. 平台与在线监管 -> 产品线页“软件能力模块”。  
5. 核心硬件与感知技术 -> 硬件中心 + 产品线硬件模块。  
6. 品牌实力与服务网络 -> About + Contact 公共模块。
