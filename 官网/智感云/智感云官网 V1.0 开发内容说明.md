## 5.2 医疗废物精细化追溯系统

### 页面标题

医疗废物精细化追溯系统

### 页面副标题

面向医疗机构、监管部门及医废相关单位，覆盖医疗废物从产生、收集、转运、暂存到出库交接的全过程管理，帮助客户实现业务过程留痕、责任追溯、异常提醒和台账归档。

### 产品定位

医疗废物精细化追溯系统是智感云核心产品。系统通过智能称重终端、RFID / 二维码标签、移动采集、院端工作台和监管驾驶舱，辅助医疗机构落实医疗废物分类管理、交接管理、暂存管理和出库管理要求。

### 业务痛点

- 人工台账依赖度高，容易出现漏填、错填、补填。

- 科室收集、院内转运、暂存出库等环节交接多，责任链条不易追溯。

- 医废重量、时间、交接人员、暂存状态等信息分散，管理效率低。

- 异常事件发现滞后，难以及时提醒和闭环处理。

- 多院区、多科室、多角色协同管理难度高。

### 核心功能

- 科室收集与分类管理：支持按科室、类别、人员、时间进行医废收集记录。

- 智能称重与标签打印：通过智能称重终端完成重量记录、标签生成和实物绑定。

- 院内转运与交接管理：记录收集、转运、暂存、出库等节点，形成责任留痕。

- 暂存间管理：支持库存查看、入库出库、暂存时间提醒和异常记录。

- 异常提醒：支持重量异常、超时未收、交接缺失、设备离线等提醒。

- 统计报表与院端驾驶舱：支持按科室、时间、类别等维度进行统计和归档。

### 业务流程图

科室产生 → 分类收集 → 智能称重 → 标签绑定 → 院内转运 → 暂存入库 → 出库交接 → 台账归档

## 5.3 危险废物“五即一码”规范化管理系统

### 页面标题

危险废物“五即一码”规范化管理系统

### 页面副标题

围绕危险废物“即产生、即包装、即称重、即打码、即入库”和“一码贯通”要求，提供源头作业、标签赋码、扫码入库、出库交接、联单关联和监管驾驶舱能力。

### 产品定位

危险废物“五即一码”规范化管理系统面向医疗机构、产废单位、危废暂存点及监管单位，结合智能称重终端、E-ink 电子标签、扫码设备、移动端和业务后台，帮助客户规范危险废物产生、暂存、转移和处置过程中的作业记录与追溯管理。

该系统面向区域医疗机构、园区、产废单位等多类型场景，可结合区域解决方案、园区方案和“智慧无废”升级思路，支撑危废全过程规范化管理。

### 业务痛点

- 危废产生、包装、称重、赋码和入库操作不够规范。

- 实物、重量、标签、责任人和台账之间容易脱节。

- 暂存、出库、转移和联单关联过程缺少有效核验。

- 小微医疗机构、园区、制造企业等不同业态作业模式差异大。

- 监管侧需要掌握纳管进度、联单状态、异常事项和整改进展。

### 核心功能

- “五即”作业办理：支持即产生、即包装、即称重、即打码、即入库流程化办理。

- 一物一码标签绑定：通过二维码、电子标签等方式绑定实物、重量、责任人和流转状态。

- 扫码入库与出库交接：支持暂存入库核验、出库扫码确认和账实一致校验。

- 电子联单关联：支持出库批次与运输、处置环节联单关联，辅助实现去向可追。

# 11\. 视觉与交互要求

## 11.1 整体风格

- 科技感

- 简洁清晰

- 蓝白色系为主

- 适度使用渐变、线性图标、卡片阴影

- 避免过度复杂动画

- PC 与移动端响应式适配

## 11.2 首页视觉建议

- Hero 使用科技感场景图或抽象网格背景；

- 产品矩阵使用卡片式布局，每张卡片可配一张产品方向插图；

- 软硬一体能力使用四个图标卡片，不在首页堆放大量软件截图和硬件照片；

- 客户覆盖使用中国地图或区域分布图；

- 客户案例使用匿名卡片；

- Footer 保持简洁。

## 11.2.1 产品详情页素材展示规则

每个产品详情页固定预留三类素材区：

1. 业务流程图区：放在“核心功能”之后，用于解释完整业务链路；

2. 软件截图区：放在业务流程图之后，用于展示系统界面、移动端、院端工作台、业务后台、监管驾驶舱等；

3. 硬件产品图区：放在软件截图之后，用于展示智能终端、标签、传感器、物联网关等硬件设备。

页面顺序建议：

产品 Hero → 产品定位 → 业务痛点 → 核心功能 → 业务流程图 → 软件截图 → 硬件产品图 → 应用价值 → CTA。

素材不足时：

- 业务流程图可先由前端用步骤卡片绘制；

- 软件截图可先使用脱敏截图或占位图；

- 硬件产品图可先使用产品渲染图或合规授权照片；

- 禁止用 AI 生成的假后台图冒充真实产品截图。

## 11.3 地图展示要求

- 展示中国区域覆盖图；

- 只展示省级或城市级聚合信息；

- 不展示具体医院、监管单位、项目地址、经纬度或精确点位；

- 地图旁展示 800+ 客户、客户类型、区域覆盖等数字信息。

## 11.4 图片与截图要求

- 产品截图使用脱敏截图或模拟截图；

- 系统后台图不展示真实客户名称、真实业务明细、患者信息、监管对象清单；

- 客户 Logo 仅在获得授权后展示；

- 项目现场照片仅在获得授权后展示。
