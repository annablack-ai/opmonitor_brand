# Note Folder

Use this folder to store daily markdown notes.

## Auto-create note by datetime

Run:

```bash
./note/new-note.sh
```

Example with a title:

```bash
./note/new-note.sh ectms-review
```

This creates files like:

- `2026-03-16_10-30-25_Daily_Note.md`
- `2026-03-16_10-31-09_ectms-review.md`
