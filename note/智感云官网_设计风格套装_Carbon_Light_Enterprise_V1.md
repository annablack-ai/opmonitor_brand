# 智感云官网设计风格套装

套装名称：Carbon Light Enterprise for OPM

适用范围：
- `website_v2_astro/` 官网前台页面
- 首页、产品列表、产品详情、案例、新闻、关于、联系页
- 后续所有静态页面、专题页与对外提案型 H5

唯一参考母版：
- IBM Carbon Design System

这份文件的作用不是讲抽象审美，而是给你一个可以直接套用的“风格套装”。

以后你只需要说一句：

`这一页按 Carbon Light Enterprise 套装做。`

就够了。

## 1. 套装定位

这是一个偏企业官网、偏医疗科技、偏专业 B2B 的浅色官网套装。

它的核心不是酷炫，而是：

1. 干净
2. 有结构
3. 有品牌感
4. 有设计感，但不吵
5. 适合医院、监管、集团客户观看

## 2. 套装气质关键词

关键词固定为：

1. 医疗科技
2. 专业可信
3. 冷静克制
4. 企业级秩序
5. 数据化表达
6. 软硬一体
7. 浅色高质感

## 3. 套装不是这些风格

明确排除：

1. 深黑蓝紫科技风
2. SaaS 营销落地页风
3. 互联网融资路演风
4. 医疗宣传册人物大图风
5. 玻璃拟态堆叠风
6. 复杂 3D 炫技风

## 4. 套装的 5 个固定视觉语言

### 4.1 语言一：浅色基底

整站必须建立在白色、浅灰蓝、浅冷灰的背景体系上。

推荐背景层级：

- 页面主底：`#F8FBFE`
- 区块浅底：`#F3F7FB`
- 弱强调底：`#EEF5FF`
- 纯白卡片底：`#FFFFFF`

### 4.2 语言二：硬边界结构

设计感主要来自结构边界，而不是来自发光或渐变。

允许使用：

1. 轻边框矩形
2. 关键分割线
3. 浅层结构平面
4. 规则圆角块面
5. 微弱的网格与秩序线

### 4.3 语言三：单一品牌蓝点亮

全站只保留一个主强调色：`#007BFF`

它只用于：

1. 主按钮
2. 重点文字
3. 关键数据
4. 重点线条
5. 局部激活态

不要把蓝色铺满整个页面。

### 4.4 语言四：大标题驱动

Carbon 的设计感很大一部分来自标题层级，而不是装饰。

所以每个页面都要遵守：

1. Hero 标题最大
2. section 标题第二级
3. 数据和卡片标题第三级
4. 说明文字永远退后

### 4.5 语言五：克制细节

动效、阴影、渐变、材质都只能是“辅助表达”，不能成为主角。

## 6. 套装字体方案

推荐字体栈：

1. 中文：`PingFang SC`, `Noto Sans SC`
2. 英文：`IBM Plex Sans`
3. 回退：`Segoe UI`, `sans-serif`

标题要求：

1. 字重要稳
2. 字形要清晰
3. 不用花体
4. 不用圆润可爱型字体

## 7. 套装排版层级

### 7.1 首页 Hero

- Hero 标题：`56-72px`
- Hero 副文：`18-22px`
- Hero 支撑说明：`16-18px`
- Hero tag：`13-14px`

### 7.2 Section

- section label：`13px`
- section title：`40-52px`
- section subtitle：`17-19px`

### 7.3 卡片

- 卡片标题：`22-28px`
- 卡片正文：`15-17px`
- 标签与注释：`12-14px`

## 8. 套装栅格

官网统一采用 12 栏思路。

建议：

1. 页面内容宽度稳定，不做大幅忽宽忽窄。
2. 区块上下留白明显大于卡片内部留白。
3. 常用垂直节奏只用 `16 / 24 / 32 / 48 / 72 / 96` 这几个级别。
4. 页面不要到处发明新间距。

## 9. 套装组件模板

### 9.1 Hero 模板

Hero 必须由四部分组成：

1. tag 行
2. 大标题
3. 支撑文案
4. 双按钮

右侧背景只允许使用：

1. 抽象结构平面
2. 关键线
3. 微网格
4. 轻材料感

不允许：

1. 假后台面板
2. 复杂流程图
3. 节点说明图
4. 浮夸大光束

### 9.2 Section Header 模板

每个区块统一只有三层：

1. label
2. title
3. subtitle

禁止再额外插入第四种风格的眉标或装饰标题。

### 9.3 数据卡模板

数据卡统一规则：

1. 白底或极浅蓝底
2. 轻边框
3. 大数字
4. 短标签
5. 不用复杂图标堆满

### 9.4 能力卡模板

能力卡统一规则：

1. 顶部小图标
2. 中间标题
3. 下方 2 到 4 行说明
4. 需要时加一行标签

### 9.5 新闻卡模板

新闻卡统一规则：

1. 时间和分类先弱化
2. 标题为主
3. 摘要不超过 3 行
4. 不做营销海报风封面

## 10. 套装中的设计感从哪里来

这个套装的设计感，不来自复杂特效，而来自下面 6 个点：

1. 标题和正文的强层级对比
2. 轻边界和规则几何块面的关系
3. 大留白里的秩序感
4. 品牌蓝只在关键位置出现
5. 每个 section 都像一个成熟模块，而不是一块散内容
6. 视觉重点永远服务信息，而不是抢信息

## 11. 套装中的按钮系统

只保留两种：

1. 主按钮：品牌蓝实底
2. 次按钮：白底蓝边

不要再发明第三种主视觉按钮。

## 12. 套装中的阴影系统

阴影只允许很轻。

建议范围：

1. 卡片阴影：`0 12px 30px rgba(15, 76, 129, 0.06)`
2. hover 阴影：`0 18px 44px rgba(0, 123, 255, 0.10)`

不要用重黑影。

## 13. 套装中的圆角系统

统一用少量圆角级别：

1. 小圆角：`12px`
2. 中圆角：`20px`
3. 大圆角：`28px`
4. pill：`999px`

不要一个页面出现很多种不相关圆角。

## 14. 套装中的图标系统

图标统一要求：

1. 线性
2. 规则
3. 轻量
4. 不写实
5. 不卡通
