- 核心系统：智能称重终端 + RFID/二维码 + 移动采集 + 院端工作台 + 监管驾驶舱
- 核心功能含：统计报表与院端驾驶舱
- 流程：科室产生 -> 分类收集 -> 智能称重 -> 标签绑定 -> 院内转运 -> 暂存入库 -> 出库交接 -> 台账归档

### 5.3 危险废物“五即一码”系统（要点）
- 五即：即产生 / 即包装 / 即称重 / 即打码 / 即入库
- 能力：联单关联 + 监管端驾驶舱

### 5.4 智慧卫监（要点）
- 支持：在线监测、实时预警、非现场执法、问题闭环
- 能力：监管驾驶舱

### 5.5 消毒灭菌监测（要点）
- 支持：关键参数监测、异常提醒、事件留痕、监管或院感查看

### 5.6 内镜合规（要点）

### 5.7 碳管理与减污降碳协同（要点）
